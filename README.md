# Simple Interest Calculator

A simple program to calculate simple interest based on principal amount, rate of interest, and time period.

## Formula
Simple Interest (SI) = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest (per annum)
- T = Time period (in years)

## Example
If P = 1000, R = 5%, T = 2 years:
SI = (1000 × 5 × 2) / 100 = 100

## How to Use
1. Input the principal amount.
2. Input the rate of interest.
3. Input the time period.
4. The program calculates and displays the simple interest.
